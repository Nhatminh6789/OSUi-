# Osui!

**Osui!** là một phiên bản web của osu!, chạy ngay trên trình duyệt.

Game hỗ trợ file **`.osz`** (beatmap) và **`.osk`** (skin) cho những người thích dùng skin và beatmap riêng của mình. Ngoài ra, Osui! bổ sung thêm **mania 4K** cho những người chơi muốn chơi mania.

## Tính năng

- Chơi beatmap từ file `.osz`
- Dùng skin từ file `.osk`
- Chế độ osu! thường
- Chế độ **mania 4K**
- Hỗ trợ tiếng Việt và tiếng Anh (đổi trong phần Cài đặt)

## Lưu ý

- Osui! **không hỗ trợ** các chế độ **taiko** và **catch**.
- Osui! **không hỗ trợ** các **mod của phiên bản lazer**.
